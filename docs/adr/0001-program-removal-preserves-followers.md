# Program removal preserves existing followers

Removing a program hides it from new selections while allowing existing followers to continue and preserving their training history. We chose this over deleting its content or forcing followers to switch programs because catalog maintenance should not interrupt a user's ongoing training. Publication requires explicit removal markers; omission from a content file fails validation so an incomplete file cannot unintentionally remove published content.

Continuation applies while the removed program remains the user's current program. All removed programs stay hidden in program choosers, including for previous followers. Switching away prevents returning while the program remains removed; training history is preserved.
