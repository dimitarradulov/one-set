# Catalog content review

`docs/HIT_Workout_Program_Library.md` defines program structure, rep ranges, TF/MMF stopping standards, global warmup steps, rest bands, and the controlled-repetition standard. It does not provide dedicated technique text for every exercise. The shared exercise YAML uses the source's global execution standard for movements without dedicated cues; it does not add movement-specific claims.

The following 27 movements currently have only that global execution standard and should receive a dedicated cue if the founder later supplies or approves one:

- 45-Degree Back Extension
- Barbell Curl
- Barbell Row
- Bulgarian Split Squat
- Cable Crunch
- Cable Lateral Raise
- Close-Grip Smith-Machine Bench Press
- Conventional Deadlift
- Dumbbell Lateral Raise
- Dumbbell Overhead Triceps Extension
- Dumbbell Rear-Delt Raise
- Dumbbell Romanian Deadlift
- Dumbbell Shrug
- Dumbbell Wrist Curl
- Front Squat
- Goblet Squat
- Hammer Curl
- Hanging Knee Raise
- Incline Dumbbell Curl
- Incline Dumbbell Press
- Incline Smith-Machine Press
- One-Arm Dumbbell Row
- Romanian Deadlift
- Smith-Machine Barbell Row
- Standing Dumbbell Shoulder Press
- Weighted Chin-Up
- Weighted Dip

The other 20 movements retain the technique cues present in the initial shared exercise seed or the Powerhouse neck note. Each exercise's stopping guidance is derived from the supplied program rows: TF or MMF follows the standard defined in the source. The catalog provides all required text fields without presenting the global execution standard as a movement-specific claim.

Do not fill these gaps by copying cues from an unrelated movement. Any future exercise-specific addition should be reviewed as catalog content before publication.
