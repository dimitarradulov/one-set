# HIT Workout Program Library for Mobile App

> Product rule: every program below follows High Intensity Training principles: brief sessions, controlled reps, hard effort, progressive overload, and recovery-first scheduling.  
> Naming rule: no program uses the name of a real person or their branded routine.

---

## Universal HIT Rules for the App

### Core Training Principles

- **Working sets:** 1 true all-out working set per exercise unless clearly marked as a warm-up or technique set.
- **Failure target:** reach **technical failure**, meaning no more clean reps can be performed without form breakdown.
- **Rep tempo:** default tempo is **3 seconds up / 1 second squeeze / 4 seconds down**. Explosive programs use a safer power-specific tempo.
- **Warm-ups:** use 1–3 progressive warm-up sets for heavy compound lifts. Warm-ups must never be taken to failure.
- **Progression:** use double progression. When the user hits the top of the rep range with clean form, increase load next time.
- **Rest between exercises:** 2–4 minutes for normal HIT, 4–6 minutes for heavy compounds, 60–90 seconds for pre-exhaust supersets.
- **Session duration:** most sessions should last 25–45 minutes.
- **Recovery:** if strength drops for 2 sessions in a row, add one extra rest day before repeating the next workout.
- **Advanced techniques:** forced reps, negatives, rest-pause, and static holds are optional and should be limited to advanced users.

### App Intensity Scale

| Level | App Label | Description |
|---|---|---|
| 7 | Hard | 2–3 reps left in reserve |
| 8 | Very Hard | 1–2 reps left in reserve |
| 9 | Near Failure | 0–1 reps left in reserve |
| 10 | HIT Failure | No clean rep possible |

Beginners should start at **Level 8–9** for the first 3–4 weeks. Intermediates and advanced users may use **Level 10** on the final working set.

### Standard Rep Ranges

| Exercise Type | Rep Range |
|---|---:|
| Heavy presses, rows, squats, deadlift variations | 6–10 |
| Machine compounds | 8–12 |
| Isolation exercises | 8–15 |
| Calves | 10–20 |
| Abs | 10–20 |
| Power lifts in athletic program | 3–6, not to grinding failure |

# Program 1 — Foundation Full-Body HIT

## Best For

Beginner lifters, returning lifters, or users learning HIT discipline.

## Weekly Schedule

Train **2–3 days per week**, never on back-to-back days.

Example:

- Monday — Workout A
- Thursday — Workout B
- Optional Saturday — Workout A, only if recovery is excellent

## HIT Rules

- 1 working set per exercise.
- Stop at technical failure, not sloppy failure.
- No forced reps or negatives.
- The goal is to learn controlled effort.

## Workout A

| Exercise | Warm-up Sets | Working Set | Target |
|---|---:|---:|---|
| Leg Press | 1–2 | 1 | 8–12 |

| Seated Row | 0–1 | 1 | 8–12 |
| Dumbbell Lateral Raise | 0 | 1 | 10–15 |

| Standing Calf Raise | 0–1 | 1 | 12–20 |
| Cable Crunch | 0 | 1 | 10–20 |

| Exercise | Warm-up Sets | Working Set | Target |
|---|---:|---:|---|
| Goblet Squat or Hack Squat | 1–2 | 1 | 8–12 |
| Incline Dumbbell Press | 1–2 | 1 | 8–12 |

When the user reaches the top of the range on all exercises in one workout, increase loads by the smallest possible jump next time.

# Program 7 — Minimalist Recovery HIT

## Best For

## Weekly Schedule

# Program 8 — Athletic Power HIT

## Best For

Users who want a dense, explosive, wrestler-like physique while still respecting HIT recovery.

## Important Safety Rule

Power movements should **not** be taken to sloppy failure. For Olympic-style lifts, the HIT principle is expressed through **high effort, low volume, maximal focus, and progressive overload**, not grinding failure.

## Weekly Schedule

Train **4 days per week** with 3 rest days.

Example:

- Monday — Power Lower + Pull
- Tuesday — Power Upper + Press
- Wednesday — Rest
- Thursday — Strength Pull + Traps
- Friday — Strength Press + Conditioning Core
- Saturday — Rest
- Sunday — Rest

## HIT Rules

- Power lifts: 3–5 crisp reps, stop before technique breaks.
- Assistance lifts: 1 working set to technical failure.
- Conditioning finishers are brief, not exhausting marathons.
- Do not combine this with hard sport practice more than 2–3 times per week.

# Program 13 — Rest-Pause Density HIT

## Best For

Advanced users who want a time-efficient high-effort routine without increasing exercise count.

## Weekly Schedule

Train **2–3 days per week**.

Example:

- Monday — A
- Thursday — B
- Optional Sunday — A

## HIT Rules

- Main working set reaches technical failure.
- Rest 15–20 seconds.
- Perform 2–4 additional mini-reps.
- Rest 15–20 seconds.
- Perform 1–3 final mini-reps.
- Use this only on safe exercises: machines, cables, dumbbell laterals, curls, pressdowns.
- Avoid rest-pause on squats, deadlifts, and Olympic lifts.

## Workout A

| Exercise | Technique | Target |
|---|---|---|

# In-App Recovery Rules

The app should ask after each workout:

1. Did performance improve?
2. Did the user sleep well?
3. Is soreness still high after 48–72 hours?
4. Did motivation drop sharply?
5. Did joints feel worse than muscles?

## Auto-Regulation Logic

| User Feedback | App Adjustment |
|---|---|
| Strength increased | Keep schedule |
| Strength flat once | Keep schedule |
| Strength flat twice | Add 1 rest day |
| Strength down twice | Deload or reduce advanced techniques |
| Joint pain | Remove risky exercise and use machine variation |
| Persistent fatigue | Switch to lower-frequency program |
| Beginner form issues | Move to Bridge or Machine Circuit |

---

# Deload Rules

Every 6–10 weeks, or when recovery markers decline:

- Keep the same exercises.
- Stop 2 reps before failure.
- Remove forced reps, negatives, and rest-pause.
- Reduce session frequency by 1 workout that week.
- Resume normal HIT when performance and motivation return.
