# HIT Workout Program Library

## Purpose

This library contains 10 distinct hypertrophy programs built around a **low-volume, high-effort, to-failure approach** suitable for a HIT-style training app.

The programs borrow the useful practical idea from traditional HIT — **few work sets performed with very high effort and tracked progression** — while applying modern evidence on hypertrophy, exercise selection, fatigue, and safety.

These are not claims that training to failure is uniquely superior. Current evidence indicates that failure is **not required** for hypertrophy and that approximately 1–2 RIR often produces similar growth with less fatigue. These templates deliberately use failure because that is the training style this library is designed to represent.

---

## Global Training Rules

### Working sets

Unless a program explicitly states otherwise:

- Perform **1 hard working set per exercise** after warm-ups.
- The working set is taken to the specified failure standard.
- Warm-up sets never count as working sets and are never taken to failure.
- Every working set is recorded as weight and reps.

### Failure standards

**MMF — Momentary Muscular Failure**<br>
Continue until another full repetition cannot be completed through the prescribed range of motion with controlled technique.

Use MMF mainly on stable machines and isolation exercises.

**TF — Technical Failure**<br>
Stop when another repetition would require meaningful technique breakdown, loss of position, or an unsafe grind.

Use TF on free-weight compounds, weighted chin-ups, weighted dips, rows, deadlift variations, and other exercises where forcing a failed repetition adds unnecessary risk.

### Repetition ranges

- Heavy compounds: **5–8** or **6–10 reps**
- Moderate compounds: **8–12 reps**
- Isolation exercises: **10–15 reps**
- Rear delts, lateral delts, neck and similar small-muscle work: **12–20 reps**

### Tempo

Use controlled repetitions rather than intentionally slow repetitions:

- Controlled eccentric
- No bouncing
- Full practical range of motion
- Strong but controlled concentric

### Rest periods

- Large compounds: **2.5–4 minutes**
- Moderate compounds: **2–3 minutes**
- Isolation exercises: **1.5–2.5 minutes**

The goal is to recover enough that the next exercise is limited by the target musculature rather than by breathlessness.

### Warm-up standard

For the first heavy exercise for a movement pattern:

1. ~40–50% of working load × 6–8 reps
2. ~65–70% × 3–5 reps
3. ~80–85% × 1–3 reps when the working load is heavy
4. Working set

For later exercises training already-warm muscles, use only the warm-up sets needed to feel technically ready.

### Progression

Use **double progression**.

Example for a 6–10 rep target:

1. Keep the load constant until the working set reaches 10 clean reps.
2. Increase the load by the smallest practical increment next session.
3. Allow reps to return toward 6–8.
4. Build back toward 10.

Do not increase load when the extra rep was achieved through shortened range of motion, bouncing, excessive body English, or technique deterioration.

### Recovery rule

Failure training has a high fatigue cost. If performance falls for several consecutive sessions, sleep and nutrition are adequate, and no illness is present, first reduce fatigue rather than adding work.

Practical options include:

- Add a rest day.
- Temporarily stop compounds at technical failure slightly earlier.
- Remove one low-priority isolation exercise.

Do not add sets automatically because a session felt short.

# App Implementation Notes

## Storage mapping

Use the current [database schema](database/oneset.dbml) and [catalog publication plan](system-design.md#catalog-publication).

- `exercises`: name, instructions, video key, default `reps_min`/`reps_max`, rest seconds and warmup guidance.
- `workout_exercises`: exercise reference, position and workout-specific `reps_min`/`reps_max`.
- `workout_session_sets`: actual exercise, weight/unit/reps, completion and historical guidance copy.

One working set is fixed. There are no separate failure, muscle-group, warmup-required, equipment or estimated-session-duration fields. TF/MMF remains source guidance to include in instructions.

## Failure labels

Include the appropriate stopping guidance in exercise instructions. The TF/MMF column in this source library is an authoring aid, not a separate database field. Its two terms are:

- **Momentary Failure**
- **Technical Failure**

Avoid presenting “absolute failure” as a target on technically demanding free-weight exercises.

## Progression state

A simple app progression rule can be:

- If reps reach the top of the target range with valid technique → recommend a load increase next session.
- If reps stay inside the range → keep the same load and attempt another rep next exposure.
- If reps fall below the range → keep actual input editable; do not automatically prescribe a load reduction or recovery intervention.

## Exercise substitutions

The programmed library intentionally contains **one definitive exercise in every exercise slot**. Do not display automatic A/B alternatives inside the workout itself. User-initiated replacements use the supplied exercise library. Remembered choices live in `user_workout_exercises`; a session-only replacement changes only that session.

# Evidence-Informed Notes

The attached research used to design this library supports several important points:

1. **Failure is not required for hypertrophy.** Training around 1–2 RIR can produce similar muscle growth while causing less acute fatigue. Failure is retained here because these are specifically HIT-style templates.
2. **Very low-volume training may make failure more useful.** When only one working set is performed, reaching very high effort may help maximize the stimulus obtained from that set.
3. **Stable exercises are better candidates for true muscular failure.** Free-weight compounds have greater technical and fatigue costs, so technical failure is the more appropriate endpoint.
4. **Exercise priority belongs early in the session.** Strength improvements consistently favor exercises trained earlier, while hypertrophy appears less sensitive to order.
5. **Exercise variety should be purposeful rather than random.** Different movement patterns and joint actions are used where they add coverage, while redundant duplicates are minimized.
6. **Compounds do not necessarily maximize development of every participating muscle.** Targeted isolation work is used to fill meaningful gaps.

## Key research represented in the project material

- Refalo et al. — proximity to failure and hypertrophy systematic review/meta-analysis.
- Grgic et al. — failure versus non-failure systematic review/meta-analysis.
- Robinson et al. — proximity-to-failure dose-response meta-regression.
- Currier et al. — resistance-training prescription and 2026 ACSM position stand.
- Nunes et al. — exercise order systematic review/meta-analysis.
- Kassiano et al. — exercise variation systematic review.
- Pelland et al. — weekly volume and frequency dose-response meta-regressions.

# Final Coaching Note

These programs are intentionally **HIT-style**, not claims that every natural bodybuilder should train to failure on every exercise forever.

The practical model is:

> **Few high-quality work sets + hard effort + stable technique + measurable progression + enough recovery.**

A set only counts as successful if the target muscle was trained hard **without sacrificing the movement standard used to compare performance from session to session**.
